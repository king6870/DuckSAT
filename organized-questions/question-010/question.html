In the coordinate plane, line L is drawn with equation y = -x + 3. A point P is located at (2,0). What is the distance from P to line L?

💡 Solution

Answer: A) $\\frac{\\sqrt{2}}{2}$

Step-by-Step Explanation:

Line L is given by $y = -x + 3$. In standard form this is $x + y - 3 = 0$, so $A = 1$, $B = 1$, $C = -3$. Distance from a point $(x_0, y_0)$ to a line $Ax + By + C = 0$ is $d = \frac{|A x_0 + B y_0 + C|}{\sqrt{A^2 + B^2}}$. With the point $P = (x_0, y_0) = (2, 0)$, we obtain $d = \frac{|1 \cdot 2 + 1 \cdot 0 - 3|}{\sqrt{1^2 + 1^2}}$. Compute the numerator: $|2 - 3| = 1$; the denominator: $\sqrt{2}$. Thus $d = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$. Therefore the distance is $\dfrac{\sqrt{2}}{2}$, which corresponds to choice $A$.
