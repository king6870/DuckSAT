Question 17 HARD
Solve for $x$: $3(2x - 5) + 4(x + 1) = 5x + 9$.
  • A) 4
  • B) 2
  • C) 1
  • D) 5
Explanation:
Expand: $3(2x - 5) + 4(x + 1) = (6x - 15) + (4x + 4) = 10x - 11$. Set equal to the right side: $10x - 11 = 5x + 9$. Subtract $5x$: $5x - 11 = 9$. Add $11$: $5x = 20$. Divide by 5: $x = 4$. Check: LHS $= 3(2\cdot 4 - 5) + 4(4 + 1) = 3(8 - 5) + 4(5) = 3(3) + 20 = 9 + 20 = 29$. RHS $= 5\cdot 4 + 9 = 20 + 9 = 29$. Balance holds, so $x = 4$ is correct.

Question 20 HARD
Solve $|2x - 3| + 4 \le 3x$.
  • A) $x \ge \frac{7}{5}$
  • B) $x \le 0$
  • C) $x \ge 4$
  • D) all real numbers
Explanation:
Do casework on the absolute value. Case 1: $2x - 3 \ge 0$ (i.e., $x \ge \tfrac{3}{2}$). Then $|2x - 3| = 2x - 3$ and $(2x - 3) + 4 \le 3x$ gives $2x + 1 \le 3x \Rightarrow x \ge 1$. Intersect with $x \ge \tfrac{3}{2}$ to get $x \ge \tfrac{3}{2}$. Case 2: $2x - 3 < 0$ (i.e., $x < \tfrac{3}{2}$). Then $|2x - 3| = -2x + 3$ and $(-2x + 3) + 4 \le 3x$ gives $-2x + 7 \le 3x \Rightarrow 7 \le 5x \Rightarrow x \ge \tfrac{7}{5}$. Intersect with $x < \tfrac{3}{2}$ to get $\tfrac{7}{5} \le x < \tfrac{3}{2}$. Union with Case 1 yields $x \ge \tfrac{7}{5}$. So the solution is $x \ge \tfrac{7}{5}$.
