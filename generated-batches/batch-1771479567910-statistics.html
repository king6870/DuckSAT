Question 17 HARD
Consider the data set {3,5,7,7,9,11}. After adding the values 1 and 13 to form {1,3,5,7,7,9,11,13}, which statement is true about the mean, median, and mode of the original and the new data sets?
  • A) The original mean, median, and mode are all 7; after adding, the new mean and new median are both 7 (the mode remains 7).
  • B) The new median is 7.5.
  • C) The new data set has two modes.
  • D) The new mean is 8.
Explanation:
Original sum: $3+5+7+7+9+11=42$, $n=6$, so mean = $42/6=7$. The data in order are 3,5,7,7,9,11; for even $n$, median = $(x_{n/2}+x_{n/2+1})/2 = (7+7)/2=7$. The mode is 7, since it occurs twice and all other values occur once. After adding 1 and 13, the sum becomes $42+1+13=56$ and $n=8$, so new mean = $56/8=7$. The new sorted data are 1,3,5,7,7,9,11,13; median = $(x_4+x_5)/2 = (7+7)/2=7$. The number 7 still occurs most often (twice), so the mode remains 7. Therefore statement A is true; B, C, and D are false.
Question 18 HARD
In a survey of 200 students, 120 like apples, 80 like bananas, and 50 like both. What fraction of students like exactly one of the two fruits?
  • A) 1/4
  • B) 1/2
  • C) 3/5
  • D) 3/8
Explanation:
Let A be the apples-likers and B be the banana-likers. Given |A|=120, |B|=80, |A∩B|=50. Exactly one equals (|A|−|A∩B|) + (|B|−|A∩B|) = (120−50) + (80−50) = 70 + 30 = 100. Fraction of exactly-one = 100/200 = 1/2. Therefore option B is correct.

The dataset {2,4,6,8,10} has population standard deviation s. If each value is transformed by x -> 2x + 3, what is the new population standard deviation? Express your answer in simplest radical form.
  • A) $2\sqrt{2}$
  • B) $4\sqrt{2}$
  • C) $6\sqrt{2}$
  • D) $\sqrt{18}$
Explanation:

Therefore option B is correct.
