Question 1 EASY
A rectangle has width $w$ and length $l$, where $l = 3w$. The perimeter is $14$ cm. Find the width.
  • A) w = 7/2 cm
  • B) w = 2 cm
  • C) w = 7/8 cm
  • D) w = 7/4 cm
Explanation:
Let width be $w$ and length be $l = 3w$. The perimeter is $2(l + w) = 14$. Substituting gives $2(3w + w) = 14$, so $2(4w) = 14$, hence $8w = 14$ and $w = 14/8 = 7/4$. Then $l = 3w = 3(7/4) = 21/4$. Check: $2(l + w) = 2(21/4 + 7/4) = 2(28/4) = 14$, which matches. Therefore the width is $7/4$ cm.
Question 2 MEDIUM
A concert sells adult tickets at $12 and student tickets at $8$. If a total of 14 tickets were sold for $144$, how many adult tickets were sold? Let $a$ denote the number of adult tickets and $s$ denote the number of student tickets. Set up and solve the system of equations: $a + s = 14$, $12a + 8s = 144$.$
  • A) 6
  • B) 8
  • C) 4
  • D) 10
Explanation:
From the system, $a + s = 14$ implies $s = 14 - a$. Substitute into $12a + 8s = 144$: $12a + 8(14 - a) = 144$. Simplify: $12a + 112 - 8a = 144$ which gives $4a = 32$ and thus $a = 8$. Then $s = 14 - 8 = 6$. Therefore, the number of adult tickets is 8.
