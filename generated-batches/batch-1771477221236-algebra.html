Question 19 HARD
A store sells two products: X at $3 per unit and Y at $4 per unit. Let x be the number of units of X sold and y be the number of units of Y sold. The total revenue is $25, so $3x + 4y = 25. In addition, twice the number of Y units exceeds the number of X units by 3, i.e., -x + 2y = 3. Solve for (x,y).
  • A) x = 19/5, y = 17/5
  • B) x = 9/5, y = 7/5
  • C) x = 6, y = 5
  • D) x = 13/5, y = 11/5
Explanation:
We have the system: $3x + 4y = 25$ and $-x + 2y = 3$. Solve by elimination: Multiply the second equation by 3 to get $-3x + 6y = 9$. Add to the first: $(3x + 4y) + (-3x + 6y) = 25 + 9$ → $10y = 34$ → $y = 34/10 = 17/5$. Substitute into $-x + 2y = 3$: $-x + 2*(17/5) = 3$ → $-x + 34/5 = 3$ → $-x = 3 - 34/5 = (15 - 34)/5 = -19/5$ → $x = 19/5$. So $(x, y) = (19/5, 17/5)$.
