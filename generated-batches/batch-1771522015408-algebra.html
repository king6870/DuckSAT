Question 3 MEDIUM
Solve the system by substitution: $\begin{cases} x + y = 6 \\ 2x - y = 1 \end{cases}$.
  • A) (7/3, 11/3)
  • B) (3, 3)
  • C) (4, 2)
  • D) (5, 1)
Explanation:
From the first equation, $y = 6 - x$. Substitute into $2x - y = 1$: $2x - (6 - x) = 1 \Rightarrow 3x = 7 \Rightarrow x = 7/3$. Then $y = 6 - 7/3 = 11/3$. So the solution is (7/3, 11/3).
Question 4 MEDIUM
Multiply the polynomials: $(2x - 3)(x + 4)$.
  • A) 2x^2 + 5x - 12
  • B) 2x^2 + x - 12
  • C) 2x^2 - 5x - 12
  • D) 2x^2 + 5x + 12
Explanation:
Use FOIL: $(2x)(x)=2x^2$, $(2x)(4)=8x$, $(-3)(x)=-3x$, $(-3)(4)=-12$. Sum the x-terms: $8x-3x=5x$. Final: $2x^2 + 5x - 12$.

Question 9 MEDIUM
Solve the system by elimination: $\begin{cases} 2x + 3y = 6 \\ 4x - y = 5 \end{cases}$.
  • A) (3/2, 1)
  • B) (0, 6)
  • C) (2, -1)
  • D) (1, 2)
Explanation:
From the second equation, $y = 4x - 5$. Substitute into the first: $2x + 3(4x - 5) = 6 \Rightarrow 2x + 12x - 15 = 6 \Rightarrow 14x = 21 \Rightarrow x = 3/2$. Then $y = 4(3/2) - 5 = 6 - 5 = 1$. So the solution is (3/2, 1).

  • C) 112
  • D) 168
Explanation:
Let T be the number of T-shirts and H the number of hoodies. T + H = 420 and 10T + 25H = 5040. Solve: from T = 420 - H, substitute: 10(420 - H) + 25H = 5040 => 4200 - 10H + 25H = 5040 => 15H = 840 => H = 56. Thus hoodies = 56.
Question 11 HARD
A theater sells adult tickets priced at $12 and student tickets priced at $8. If 120 tickets were sold and the total revenue was $1080, how many adult tickets were sold?$
  • A) 30
  • B) 20
  • C) 40
  • D) 50
Explanation:
Let a be the number of adult tickets and s be the number of student tickets. The equations are a + s = 120 and 12a + 8s = 1080. From the first, s = 120 - a. Substitute into the second: 12a + 8(120 - a) = 1080 $\Rightarrow$ 12a + 960 - 8a = 1080 $\Rightarrow$ 4a = 120 $\Rightarrow$ a = 30. Therefore, the correct answer is 30, which corresponds to option A. $a = 30$.
Question 12 HARD
Solve the absolute-value inequality: |2x - 3| ≤ x + 7.
  • A) $-rac{4}{3} \le x \le 10$
  • B) $-7 \le x \le 10$
  • C) $-rac{4}{3} \le x < \frac{3}{2}$
  • D) $(-\infty, -\frac{4}{3}] \cup [10, \infty)$
Explanation:
We require x + 7 ≥ 0, so x ≥ -7. Consider two cases: Case 1: x ≥ 3/2. Then |2x - 3| = 2x - 3, and 2x - 3 ≤ x + 7 gives x ≤ 10, so 3/2 ≤ x ≤ 10. Case 2: x < 3/2. Then |2x - 3| = -(2x - 3) = -2x + 3, and -2x + 3 ≤ x + 7 gives -3x ≤ 4, so x ≥ -4/3. With x < 3/2, this gives -4/3 ≤ x < 3/2. Unioning the two cases yields -4/3 ≤ x ≤ 10. The correct option is A.
Question 13 HARD
A rectangular tile has length (2x - 3) and width (x^2 + 4x - 5). What is its area as a polynomial in x?
  • A) $2x^3 + 5x^2 - 22x + 15$
  • B) $2x^3 + 6x^2 - 32x + 15$
  • C) $2x^3 + 5x^2 - 7x + 15$
  • D) $2x^3 + 2x^2 - 22x + 15$
Explanation:
Compute the product: (2x - 3)(x^2 + 4x - 5) = 2x·x^2 + 2x·4x + 2x·(-5) - 3·x^2 - 3·4x - 3·(-5) = 2x^3 + 8x^2 - 10x - 3x^2 - 12x + 15 = 2x^3 + 5x^2 - 22x + 15.
